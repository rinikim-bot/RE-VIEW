미분류 채널 분류 도구

팀원들의 미분류 채널 목록을 Gemini로 한 번에 분류하고, 사람이 검수한 뒤 채널 DB 파일로 만들어요.

꼭 읽어 주세요. 무료 Gemini API에 보낸 내용은 구글이 서비스 개선에 쓸 수 있어요. 그래서 이 도구에는 팀원 본인의 시청기록에서 나온 목록만 넣어 주세요. 사이트 사용자의 기록은 넣지 않아요. API 키는 이 페이지를 닫으면 사라지고, 어디에도 저장되지 않아요.

1API 키 넣기

Google AI Studio에서 무료 API 키를 만든 뒤 붙여 넣으세요.

빠르고 무료 한도가 넉넉한 Flash-Lite 계열을 먼저 골라 두어요.

2미분류 채널 목록 붙여 넣기

사이트의 상세 분석 → 미분류 채널 CSV 복사로 복사한 내용을 붙여 넣으세요. 여러 팀원의 목록을 이어서 붙여 넣어도 돼요. 같은 채널은 하나로 합치고, 이미 채널 DB에 있는 채널은 빼요.

3Gemini로 분류하기

많이 본 채널부터 묶어서 물어봐요. 무료 한도에 걸리면 잠시 기다렸다가 이어서 해요. 창을 닫아도 분류 결과는 이 브라우저에 남아 있어서, 다음에 같은 목록을 넣으면 이어서 할 수 있어요.

4검수하기

AI 답은 틀릴 수 있어요. 유형이 틀렸으면 고치고, 확실하지 않은 채널은 체크를 빼 주세요. 체크된 채널만 DB에 들어가요. 확신도가 낮음이거나 모름인 채널은 처음부터 체크가 빠져 있어요.

넣기채널본 횟수본 영상 제목유형확신도AI 메모
아직 목록이 없어요.

5채널 DB 파일 만들기

체크한 채널을 지금 채널 DB에 더한 새 파일 두 개를 내려받아요. GitHub의 data 폴더에 있는 같은 이름의 파일 두 개를 이 파일로 바꿔 올리면 사이트에 바로 반영돼요.

  1. channel-types.json: 채널 DB 원본
  2. channel-types.js: 같은 내용 (index.html을 더블클릭해서 열 때 필요)
