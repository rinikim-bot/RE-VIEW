# 미분류 채널을 Gemini로 분류해 채널 DB 채우기 (팀 전용)

사이트 사용자의 시청기록은 AI에 보내지 않습니다. **팀원 본인 기록에서 나온 미분류 채널 목록만** 사용합니다.

1. 각자 사이트에서 자기 Takeout 파일을 분석 → **상세 분석 → 미분류 채널 CSV 복사**
   (채널 이름, 채널 ID, 본 횟수, 본 영상 제목 최대 3개가 복사됨)
2. 프로젝트 폴더의 `tools/classify.html`을 브라우저로 열기 (더블클릭 가능)
3. Google AI Studio(https://aistudio.google.com/apikey)에서 무료 API 키 발급 → 붙여 넣기 → **모델 불러오기**
4. 팀원들의 CSV를 이어서 붙여 넣기 → **목록 정리하기** (중복 합치기, 이미 DB에 있는 채널 빼기)
5. **분류 시작** → 많이 본 채널부터 50개씩 물어봄
   - 무료 한도에 걸리면 기다렸다 이어서 함. 하루 한도를 다 쓰면 다음 날 다시 누르면 이어서 함 (결과는 브라우저에 저장됨)
6. **검수**: 틀린 유형은 고치고, 애매한 채널은 체크 해제. 확신도 '낮음·모름'은 처음부터 체크가 빠져 있음
7. **DB 파일 2개 내려받기** → `channel-types.json`, `channel-types.js`를 GitHub의 `data` 폴더에 함께 올리기

추가된 채널에는 `classificationMethod: "gemini"`(사람이 고친 경우 `"gemini_then_human"`)와
`dataStatus: "ai_reviewed"`가 붙어서, 사람이 직접 정한 분류와 구분됩니다.
